# Агро-калькулятор смешивания химии

Консольное приложение на Python для расчёта дозировок препаратов
при опрыскивании сельскохозяйственных культур. Помогает фермерам
(КФХ и ЛПХ) рассчитать количество препарата на бак опрыскивателя,
общее количество воды на поле и проверить безопасность концентрации.

## Возможности

- Расчёт площади поля двумя способами: по длине × ширине или по готовому значению в гектарах
- Поддержка опрыскивателей с 1–4 баками
- База препаратов для трёх культур: картофель, зерновые, подсолнечник/кукуруза
- Расчёт нормы препарата на каждый бак и на всю заправку
- Проверка концентрации на безопасность (по лимиту из базы)
- Возможность указать свою норму расхода вместо рекомендуемой
- Сохранение результата в `.txt`-файл с датой и временем

## Требования

- Python 3.10 или выше
- Стандартная библиотека (`json`, `datetime`) — внешних зависимостей нет

## Установка

```bash
git clone https://github.com/ILYA-SHULICHENKO/Agro_calc.git
cd Agro_calc

# Создать виртуальное окружение (рекомендуется)
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```
# Запуск
python fertilizer_mix_calculator.py
